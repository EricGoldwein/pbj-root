PBJ320 · For AI agents

PBJ320 for agents.

PBJ320 makes public nursing home staffing and ownership data easier to research across time. Connect an AI agent to search facilities, examine staffing, trace ownership, compare providers, and inspect the CMS sources behind a finding.

The underlying data is public. PBJ320’s job is to normalize it, connect it, preserve its history, and make the methodology and evidence inspectable.

The tools

Six read-only tools. Names match tools/list.

  • search_facilities

    Find nursing homes by name, CCN, city, state, ZIP, or owner PAC.

  • get_facility

    Latest quarterly staffing, CMS provider context, state percentiles, and the canonical facility page.

  • compare_facilities

    Compare an explicit list of CCNs using the same quarterly metrics and state-percentile context.

  • search_owners

    Search CMS SNF ownership records by name or 10-digit PAC.

  • get_owner_portfolio

    Facilities attributed to a CMS associate/PAC under PBJ320’s ownership methodology.

  • get_staffing_evidence

    CMS inputs and PBJ320-derived HPRD for one facility, one date, and one metric.

PBJ320’s public facility pages preserve quarterly staffing history from 2017 forward. The current MCP uses the latest loaded quarter for facility lookup and comparison; the canonical page provides the longer historical view.

Sources and methodology

PBJ320 relies primarily on federal CMS data. Responses identify the source and reporting period. When a value is calculated by PBJ320 rather than published directly by CMS, the response says so and links to methodology.

Primary CMS sources

  • Payroll-Based Journal
  • Provider Information
  • SNF All Owners

Designed for research, not bulk extraction

PBJ320’s MCP is designed to answer research questions, not expose the normalized corpus as a bulk-download API.

  • bounded searches
  • no arbitrary SQL/database browsing
  • daily evidence requires one CCN + date + metric; no date-range exports
